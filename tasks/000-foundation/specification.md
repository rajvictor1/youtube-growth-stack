# Repository foundation

## Goal

Create an open-source, agent-readable foundation for the voice-first YouTube Growth Stack.

## Acceptance criteria

- Next.js, React, TypeScript, Tailwind, and shadcn/ui are configured.
- Realtime sessions use `gpt-realtime-2.1` and server-minted client secrets.
- Voice and text share one session and support interruption and approvals.
- YouTube, Apify, Firecrawl, Supabase, and job boundaries are explicit.
- The README includes product, runtime, repository, conversation, loop, and roadmap diagrams.
- Root and nested agent instructions exist.
- Repo-local skills validate.
- Lint, type checks, unit tests, build, and production dependency audit pass.
- The repository is published under the MIT license only after secret checks.
