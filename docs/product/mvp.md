# MVP definition

## In scope

- Supabase authentication and one-owner projects.
- Add and monitor 3–10 YouTube competitors.
- Manual research runs with visible status.
- Official YouTube API as the primary metadata source.
- Apify for explicitly configured YouTube enrichment.
- Firecrawl for external web research, not duplicate YouTube scraping.
- Outlier scoring and pattern summaries.
- Evidence-backed idea generation.
- Voice-first conversation using `gpt-realtime-2.1`.
- Persistent text transcripts and idea board.

## Out of scope for the first release

- Automatic publishing to YouTube.
- Billing and team workspaces.
- Fully autonomous production changes.
- Continuous background monitoring without quotas.
- Permanent raw microphone recording.
- Thumbnail generation or copying competitor creative.

## MVP completion bar

A new user can configure the required services, create a project, add competitors, start a research run with approval, inspect source-backed outliers, generate ideas, save one idea, and complete the workflow through voice or text without exposing credentials.
