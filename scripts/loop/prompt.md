# Bounded delivery loop

Implement exactly the supplied user story.

1. Read the repository `AGENTS.md`, nearest nested instructions, specification, and progress log.
2. Inspect the current implementation and tests before editing.
3. Implement only the selected story and its acceptance criteria.
4. Add or update focused tests.
5. Run the smallest relevant checks, then `npm run verify` when feasible.
6. Mark `passes: true` only when the acceptance criteria and checks actually pass.
7. Append concise, reusable facts to the feature `progress.md`.

Boundaries:

- Do not work on another story.
- Do not expose, print, or commit secrets.
- Do not apply remote database migrations.
- Do not create cloud resources, spend provider credits, publish packages, push commits, open pull requests, or merge.
- Do not perform destructive operations.
- If authority, credentials, or a material product decision is missing, leave the story failing and report the blocker.
